# Vital N Guide

A dependency-free, single-page prototype. Open `index.html` directly, or serve this folder with any simple local web server.

## Media filenames

Place unmodified media files at these paths:

- `assets/videos/rice-seed.mp4`
- `assets/videos/rice-seedling.mp4`
- `assets/videos/corn.mp4`
- `assets/videos/vegetables-onion.mp4`
- `assets/videos/final-common.mp4`
- `assets/videos/intro.mp4` (muted welcome-screen background)
- `assets/audio/choose-crop.mp4` (optional)
- `assets/audio/rice-method.mp4` (optional)

If your files use different names or formats, update the `media` object in `app.js` and the `data-audio` values in `index.html`.
